## 📌 Overview

Day 03 focuses on understanding how SQL is categorized into different sublanguages based on operations performed over a database.

The five SQL sublanguages studied today are **DDL, DML, DQL, TCL, and DCL**, along with the important SQL commands associated with each category.

## 🧠 Key Takeaways

### DDL — Data Definition Language

DDL is used to define and modify database structure.

**Commands:**

`CREATE` `ALTER` `DROP` `TRUNCATE`

### DML — Data Manipulation Language

DML is used to manipulate data.

**Commands:**

`INSERT` `UPDATE` `DELETE` `MERGE`

### DQL — Data Query Language

DQL is used to retrieve data.

**Command:**

`SELECT`

### TCL — Transaction Control Language

TCL is used to manage transactions.

**Commands:**

`COMMIT` `ROLLBACK` `SAVE TRANSACTION`

### DCL — Data Control Language

DCL is used to control database access and permissions.

**Commands:**

`GRANT` `REVOKE`
