# Day 03 – Quick Notes

## SQL Sublanguages

| Sublanguage | Meaning | Commands |
|---|---|---|
| DDL | Structure | CREATE, ALTER, DROP, TRUNCATE |
| DML | Data | INSERT, UPDATE, DELETE, MERGE |
| DQL | Retrieve | SELECT |
| TCL | Transaction | COMMIT, ROLLBACK, SAVE TRANSACTION |
| DCL | Control | GRANT, REVOKE |

## 🧠 Easy Memory

DDL → Structure 🏗️

DML → Data 📝

DQL → Retrieve 🔍

TCL → Transaction 🔄

DCL → Control 🔐
