# Day 03 – Interview Questions

Q1. What are SQL sublanguages?

A: SQL is categorized into five sublanguages: DDL, DML, DQL, TCL, and DCL.

Q2. What is DDL?

A: DDL is used to define and modify database structure.

Commands: CREATE, ALTER, DROP, TRUNCATE.

Q3. What is DML?

A: DML is used to manipulate data.

Commands: INSERT, UPDATE, DELETE, MERGE.

Q4. What is DQL?

A: DQL is used to retrieve data.

Command: SELECT.

Q5. What is TCL?

A: TCL is used to manage transactions.

Commands: COMMIT, ROLLBACK, SAVE TRANSACTION.

Q6. What is DCL?

A: DCL is used to control database access and permissions.

Commands: GRANT, REVOKE.

Q7. Which commands belong to DDL?

A: CREATE, ALTER, DROP, and TRUNCATE.

Q8. Which commands belong to DML?

A: INSERT, UPDATE, DELETE, and MERGE.

Q9. Which command belongs to DQL?

A: SELECT.

Q10. Which commands belong to TCL?

A: COMMIT, ROLLBACK, and SAVE TRANSACTION.

Q11. Which commands belong to DCL?

A: GRANT and REVOKE.
