# 🧠 Day 16 — SQL Server Numeric & Conversion Functions — Interview Questions

## 📌 Basic Interview Questions

### 1. What are Numeric/Mathematical Functions in SQL Server?

Numeric/Mathematical Functions are used to perform calculations and manipulate numeric values.

Examples:

- `ROUND()`
- `FLOOR()`
- `CEILING()`

---

### 2. What is the use of `ROUND()`?

`ROUND()` is used to round a numeric value to a specified number of decimal places.

### Syntax

```sql
ROUND(number, decimal_places)
