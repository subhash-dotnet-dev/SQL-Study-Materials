Q1. What is SQL?
SQL (Structured Query Language) 

SQL is a standard language used to interact with relational databases to retrieve, insert, update, and delete data.

Q2. What is T-SQL?
T-SQL (Transact-SQL)
 
T-SQL is Microsoft's procedural extension of SQL used with SQL Server. It provides additional programming features such as variables, conditions, loops, error handling, stored procedures, and functions.

Q3. What is DBMS?
A: DBMS = (Database Management System)

DBMS is software used to create, store, retrieve, update, and manage data in databases.

Q4. What is RDBMS?
RDBMS (Relational Database Management System) 

RDBMS is a type of DBMS that stores data in tables and maintains relationships between those tables.

Example:
SQL Server, Oracle, MySQL

Q5. What is ORDBMS?
A: ORDBMS = (Object-Relational Database Management System)

It combines relational and object-oriented features.

Example:
PostgreSQL

Q6. What is a Primary Key?
A: A Primary Key uniquely identifies each record and cannot contain NULL.

Example:
EmployeeId → PK

Q7. What is a Foreign Key?
A: A Foreign Key establishes a relationship between two tables.

Example:
Employee.DeptId → Department.DeptId

Q8. What is OLTP?
A: OLTP = Online Transaction Processing.
It is used for day-to-day transactions.

Q9. What is OLAP?
A: OLAP = Online Analytical Processing.
It is used for data analysis and reporting.
OLTP → Transactions
OLAP → Analysis
