## 🧠 Key Takeaways

### SQL
SQL is used to interact with relational databases for operations such as retrieving, inserting, updating, and deleting data.

### T-SQL
T-SQL (Transact-SQL) is Microsoft's extension of SQL used with SQL Server. It adds programming capabilities such as variables, conditions, loops, error handling, stored procedures, and functions.

### DBMS
A Database Management System is software used to create, store, retrieve, update, and manage data.

### RDBMS
A Relational Database Management System organizes data into tables and supports relationships between related tables.

### Primary Key
A Primary Key uniquely identifies each record in a table.

### Foreign Key
A Foreign Key creates a relationship between tables by referencing a key in another table.

### OLTP
Online Transaction Processing is designed for frequent day-to-day database transactions.

### OLAP
Online Analytical Processing is designed for analysis, reporting, and decision-making.
