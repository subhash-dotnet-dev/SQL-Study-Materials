# 📅 Day 1 — SQL Fundamentals

## SQL

Structured Query Language.

Used to interact with relational databases.

## T-SQL

Transact-SQL.

Microsoft's procedural extension of SQL used with SQL Server.

## DBMS

Database Management System.

Software used to create, store, retrieve, update and manage data.

## RDBMS

Relational Database Management System.

Stores data in tables and maintains relationships between tables.

Examples:

* SQL Server
* Oracle
* MySQL

## ORDBMS

Object-Relational Database Management System.

Combines relational and object-oriented features.

Example:

* PostgreSQL

## Primary Key

* Uniquely identifies each record
* Cannot contain NULL

## Foreign Key

* Establishes relationship between tables
* References a key in another table

## OLTP

Online Transaction Processing.

Used for day-to-day transactions.

## OLAP

Online Analytical Processing.

Used for analysis and reporting.

## ⚡ Quick Revision

SQL → Language

T-SQL → Microsoft's SQL extension

DBMS → Manages databases

RDBMS → Related tables

ORDBMS → Relational + Object-Oriented

Primary Key → Unique record identification

Foreign Key → Table relationship

OLTP → Transactions

OLAP → Analysis
