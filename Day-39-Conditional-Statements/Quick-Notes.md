## 1. Conditional Statements

Conditional statements are used to execute different statements based on conditions in T-SQL.

T-SQL mainly supports:

- IF-ELSE
- MULTI IF / ELSE IF
- NESTED IF

```text
Conditional Statements
        ↓
Condition Checking
        ↓
IF-ELSE + ELSE IF + NESTED IF
