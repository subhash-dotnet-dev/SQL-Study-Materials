# Day 04 – Interview Questions

Q1. What is Data?

A: Data is the actual value stored in a database.

Example:

100 | Subhash | 4500


Q2. What is Metadata?

A: Metadata is information that describes the data.

Example:

EmpId | Ename | Sal


Q3. What is SSMS?

A: SSMS is a tool used to connect to and manage SQL Server.


Q4. How do you connect to SQL Server?

A: Open SSMS, enter the required server and authentication details, and click Connect.


Q5. How can you create a database using GUI?

A: In SSMS, select Databases → New Database, enter the database name, and click OK.


Q6. How can you create a database using a command?

A: Use the CREATE DATABASE command.

CREATE DATABASE BATCH2930;


Q7. What is an MDF file?

A: MDF is the main data file that stores database data.


Q8. What is an LDF file?

A: LDF is the log file that stores information about database operations.


Q9. What is the difference between MDF and LDF?

A: MDF stores data, while LDF stores log information.
