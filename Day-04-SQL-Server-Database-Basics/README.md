## 📌 Overview

Day 04 focuses on understanding **Data, Metadata, SQL Server connection, SSMS, database creation, and SQL Server database files**.

The session also covered creating a database using both the **SSMS GUI method** and the **command method**.

---

## 🎯 Learning Objectives

By the end of Day 04, the focus was on understanding:

- Data and Metadata
- Connecting to SQL Server using SSMS
- SQL Server connection details
- Creating a database using GUI
- Creating a database using a command
- MDF and LDF files
- SQL Server and SSMS setup
