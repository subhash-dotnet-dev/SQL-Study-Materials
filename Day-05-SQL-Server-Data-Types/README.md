## 🧠 Key Takeaways

### Data Type

A data type defines the type of data allowed in a column and the memory allocated for it.

### Integer

SQL Server integer types include:

`tinyint`, `smallint`, `int`, `bigint`

### Numeric

Numeric types include:

`numeric(p,s)`, `decimal(p,s)`, `float`

### Currency

Currency types include:

`smallmoney`, `money`

### Date/Time

Date and time types include:

`date`, `time`, `datetime`

### ASCII

ASCII character types:

`char`, `varchar`, `varchar(max)`

### Unicode

Unicode character types:

`nchar`, `nvarchar`, `nvarchar(max)`

### Quick Difference

| Type | Meaning |
|---|---|
| CHAR | Fixed-length ASCII |
| VARCHAR | Variable-length ASCII |
| NCHAR | Fixed-length Unicode |
| NVARCHAR | Variable-length Unicode |
| FLOAT | Approximate numeric |
| DECIMAL | Precise numeric |
