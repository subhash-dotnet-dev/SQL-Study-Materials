# Day 05 — Quick Notes

## Data Type

Defines the type of data allowed in a column and memory allocated for it.

## Integer

`tinyint` | `smallint` | `int` | `bigint`

## Numeric

`numeric(p,s)` | `decimal(p,s)` | `float`

## Currency

`smallmoney` | `money`

## Date / Time

`date` | `time` | `datetime`

## ASCII

`char` | `varchar` | `varchar(max)`

## Unicode

`nchar` | `nvarchar` | `nvarchar(max)`

## Quick Differences

| Type | Key Point |
|---|---|
| CHAR | Fixed + ASCII |
| VARCHAR | Variable + ASCII |
| NCHAR | Fixed + Unicode |
| NVARCHAR | Variable + Unicode |
| FLOAT | Approximate |
| DECIMAL | Precise |
