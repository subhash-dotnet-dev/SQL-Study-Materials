# Day 05 — Interview Questions

Q24. What is a Data Type?
Answer: It defines the type of data and memory allowed in a column.

Q25. What are the main SQL Server data types?
Answer: Character, Integer, Numeric, Float, Currency, and Date/Time.

Q26. What are integer data types?
Answer: `tinyint`, `smallint`, `int`, `bigint`.

Q27. What are currency data types?
Answer: `smallmoney`, `money`.

Q28. What are date/time data types?
Answer: `date`, `time`, `datetime`.

Q29. What are numeric data types?
Answer: `numeric(p,s)`, `decimal(p,s)`.

Q30. What are character categories?
Answer: ASCII and Unicode.

Q31. What are ASCII data types?
Answer: `char`, `varchar`, `varchar(max)`.

Q32. What are Unicode data types?
Answer: `nchar`, `nvarchar`, `nvarchar(max)`.

Q33. CHAR vs NCHAR?
Answer: `CHAR` → Fixed + ASCII, `NCHAR` → Fixed + Unicode.

Q34. VARCHAR vs NVARCHAR?
Answer: `VARCHAR` → Variable + ASCII, `NVARCHAR` → Variable + Unicode.

Q35. FLOAT vs DECIMAL?
Answer: `FLOAT` → Approximate, `DECIMAL` → Precise.
