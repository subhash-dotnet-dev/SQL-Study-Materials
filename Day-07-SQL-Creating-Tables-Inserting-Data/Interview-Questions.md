# Day 07 — Interview Questions

Q37. What is CREATE TABLE?

Answer: CREATE TABLE is used to create a table structure or metadata.

Q38. What does table structure contain?

Answer: Table structure contains columns, data types, and sizes.

Q39. What are the rules for table names?

Answer: A table name should start with an alphabet, should not contain spaces or special characters, and can contain _, $ and #.

Q40. What is the maximum length of a table name?

Answer: A table name can be up to 128 characters.

Q41. What is SP_HELP?

Answer: SP_HELP is used to view the structure of a table.

Q42. What is INSERT command?

Answer: INSERT command is used to insert data into a table.

Q43. What are the types of row insertion using INSERT?

Answer: Single row and multiple rows.

Q44. What is NULL?

Answer: NULL represents a blank or empty value.

Q45. Is NULL equal to 0?

Answer: No. NULL is not equal to 0.

Q46. Is NULL equal to space?

Answer: No. NULL is not equal to space.

Q47. How can NULL values be inserted?

Answer: NULL values can be inserted directly or by specifying only the required columns.

Q48. What happens to unspecified columns during INSERT?

Answer: The unspecified columns are filled with NULL values.
