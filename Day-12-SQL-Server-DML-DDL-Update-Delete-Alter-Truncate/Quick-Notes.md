# Day 12 - SQL Server DML & DDL Commands

## 📚 DML - Data Manipulation Language

DML commands work with table data (rows).

### Main DML Commands

- INSERT
- UPDATE
- DELETE
- MERGE

---

## 🔹 UPDATE

Used to modify existing data in a table.

### Syntax

```sql
UPDATE tablename
SET colname = value
[WHERE condition];
