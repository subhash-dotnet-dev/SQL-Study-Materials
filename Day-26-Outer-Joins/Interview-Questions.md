## 📌 Basic Questions

### 1. What is an OUTER JOIN?

An OUTER JOIN is used to retrieve matching records along with unmatched records from one or both tables.

SQL Server supports three types of OUTER JOIN:

- LEFT JOIN
- RIGHT JOIN
- FULL JOIN

---

### 2. What is the difference between INNER JOIN and OUTER JOIN?

**INNER JOIN** returns only matching records.

**OUTER JOIN** can return matching as well as unmatched records.

```text
INNER JOIN
→ Matching records only

OUTER JOIN
→ Matching + Unmatched records
