# 🗄️ Day 39 — SQL Server: Conditional Statements

## 📌 Quick Notes

### 1. Conditional Statements

Conditional statements are used to execute SQL statements based on a condition.

Main types:

- IF-ELSE
- MULTI IF / ELSE IF
- NESTED IF

---

## 2. IF-ELSE

Used when there are two possible paths.

### Syntax

```sql
IF condition
BEGIN
    statements
END
ELSE
BEGIN
    statements
END
