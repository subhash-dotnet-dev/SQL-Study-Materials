## 🧠 Key Takeaways

### SQL Server

SQL Server is an **RDBMS developed by Microsoft** for storing, managing, and retrieving data.

### SSMS

SSMS stands for **SQL Server Management Studio**.

It is Microsoft's tool used to connect to SQL Server, execute queries, and manage database objects.

### SQL Server Instance

An Instance is a **running SQL Server environment** that manages databases and uses system resources.

### Database vs Instance

A **Database** stores data and database objects, while an **Instance** provides the running environment that manages those databases.

### SQL Query

A SQL Query is a **command used to perform an operation on a database**.
