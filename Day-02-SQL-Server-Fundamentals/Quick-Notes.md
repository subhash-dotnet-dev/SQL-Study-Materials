# Day 2 – Quick Notes

SQL Server → Microsoft's RDBMS for storing, managing, and retrieving data.

SSMS → Microsoft's tool for connecting to SQL Server, executing queries, and managing database objects.

Instance → Running SQL Server environment that manages databases and uses system resources.

Database → Stores data and database objects.

Instance vs Database →
Database = Stores data and objects
Instance = Provides the running environment

SQL Query → Command used to perform an operation on a database.
