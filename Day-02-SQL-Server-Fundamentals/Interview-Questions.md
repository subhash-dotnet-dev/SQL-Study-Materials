# Day 2 – Interview Questions

Q1. What is SQL Server?

A: SQL Server is an RDBMS developed by Microsoft for storing, managing, and retrieving data.

Q2. What is SSMS?

A: SSMS stands for SQL Server Management Studio. It is Microsoft's tool used to connect to SQL Server, execute queries, and manage database objects.

Q3. What is an Instance?

A: An instance is a running SQL Server environment that manages databases and uses system resources.

Q4. What is the difference between Database and Instance?

A: A database stores data and database objects, while an instance provides the running environment that manages those databases.

Q5. What is a SQL Query?

A: A SQL query is a command used to perform an operation on a database.
