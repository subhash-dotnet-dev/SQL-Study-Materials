# Day 13 — SQL Server Built-in Functions Interview Questions

## 1. What is a function?

A function accepts input, performs an operation or calculation, and returns a value.

---

## 2. What are the major types of SQL Server functions?

Common categories include:

- Date Functions
- Character / String Functions
- Numeric / Mathematical Functions
- Conversion Functions
- Special Functions
- Analytical Functions
- Aggregate Functions

---

## 3. What is GETDATE()?

`GETDATE()` returns the current date and time of the SQL Server system.

```sql
SELECT GETDATE();
