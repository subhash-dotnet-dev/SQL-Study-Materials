# Day 06 — Interview Questions

Q37. What is CHAR?
Answer: CHAR stores fixed-length ASCII character data.

Q38. What is VARCHAR?
Answer: VARCHAR stores variable-length ASCII character data.

Q39. What is VARCHAR(MAX)?
Answer: VARCHAR(MAX) stores variable-length character data up to 2GB.

Q40. What is the difference between CHAR and VARCHAR?
Answer: CHAR is fixed-length, while VARCHAR is variable-length.

Q41. What does N represent in NCHAR and NVARCHAR?
Answer: N represents Unicode character data.

Q42. What is the difference between VARCHAR and NVARCHAR?
Answer: VARCHAR stores ASCII data, while NVARCHAR stores Unicode data.

Q43. What are the integer data types?
Answer: TINYINT, SMALLINT, INT, and BIGINT.

Q44. What is TINYINT?
Answer: TINYINT uses 1 byte and stores values from 0 to 255.

Q45. What is DECIMAL(p,s)?
Answer: p represents total digits and s represents digits after the decimal point.

Q46. What is the maximum precision of DECIMAL?
Answer: The maximum precision is 38 digits.

Q47. What is the difference between DATE, TIME, and DATETIME?
Answer: DATE stores date, TIME stores time, and DATETIME stores both.

Q48. What are currency data types?
Answer: SMALLMONEY and MONEY.

Q49. What are binary data types?
Answer: BINARY, VARBINARY, and VARBINARY(MAX).

Q50. What is the difference between BINARY and VARBINARY?
Answer: BINARY is fixed-length, while VARBINARY is variable-length.
