# 👁️ DROP VIEW

`DROP VIEW` is used to remove an existing View from the database.

### Syntax

```sql
DROP VIEW V1;
```

### Important Point

If the base table is dropped, the View remains in the database but cannot be queried successfully because its underlying table no longer exists.

### Example

```sql
CREATE VIEW V1
AS
SELECT *
FROM EMP;
```

To remove the View:

```sql
DROP VIEW V1;
```

---

# 🔗 SYNONYMS

A **Synonym** is an alternative name for a database object such as a table or View.

### Create Synonym

```sql
CREATE SYNONYM E
FOR EMP;
```

Now `E` can be used as an alternative name for `EMP`.

### Using Synonym

```sql
SELECT *
FROM E;
```

### Drop Synonym

```sql
DROP SYNONYM E;
```

### Synonym Flow

```text
EMP TABLE

   ↓

CREATE SYNONYM

   ↓

E

   ↓

SELECT * FROM E
```

# 🏗️ SCHEMA

A **Schema** is used to logically group and organize related database objects.

### Create Schema

```sql
CREATE SCHEMA SALES;
```

### Create Table Under Schema

```sql
CREATE TABLE SALES.CUST
(
    CID INT,
    CNAME VARCHAR(10),
    ADDR VARCHAR(20)
);
```

The table is identified as:

```text
SALES.CUST
```

### Access Table

```sql
SELECT *
FROM SALES.CUST;
```

### Schema Structure

```text
DATABASE
   ↓
SCHEMA
   ↓
DATABASE OBJECTS
   ↓
TABLES / VIEWS / SYNONYMS
```

# 🔄 SYNONYM vs ALIAS

A **Synonym** and an **Alias** both provide alternative names, but they work at different levels.

| SYNONYM                        | ALIAS                         |
| ------------------------------ | ----------------------------- |
| Stored in Database             | Query Level                   |
| Permanent Database Object      | Not Stored as Database Object |
| Database Scope                 | Query Scope                   |
| Created using `CREATE SYNONYM` | Created using `AS`            |
| Can be reused                  | Used within the query         |

### Synonym Example

```sql
CREATE SYNONYM E
FOR EMP;
```

```sql
SELECT *
FROM E;
```

### Alias Example

```sql
SELECT
    E.EMPNAME AS EmployeeName
FROM EMP AS E;
```

### Easy Memory Trick

```text
SYNONYM
   ↓
DATABASE LEVEL

ALIAS
   ↓
QUERY LEVEL
```

# 🔢 SEQUENCES

A **Sequence** is a database object used to generate sequential numeric values.

### Create Sequence

```sql
CREATE SEQUENCE S1
START WITH 1
INCREMENT BY 1
MAXVALUE 5;
```

The Sequence can generate:

```text
1
2
3
4
5
```

### Sequence Flow

```text
SEQUENCE

   ↓

START WITH 1

   ↓

INCREMENT BY 1

   ↓

1 → 2 → 3 → 4 → 5
```

---

# ➡️ NEXT VALUE FOR

`NEXT VALUE FOR` is used to retrieve the next value generated by a Sequence.

### Example

```sql
INSERT INTO STUDENT
VALUES
(
    NEXT VALUE FOR S1,
    'A'
);
```

Each execution gets the next available value from the Sequence.

### Example Flow

```text
S1

↓

1

↓

NEXT VALUE FOR S1

↓

2

↓

NEXT VALUE FOR S1

↓

3
```

---

# ♻️ CYCLE & NOCYCLE

Sequences can be configured to either restart or stop after reaching their limits.

## 🔄 CYCLE

`CYCLE` allows the Sequence to restart after reaching its maximum value.

```text
1 → 2 → 3 → 4 → 5
                ↓
             RESTART
                ↓
                1
```

### Example

```sql
CREATE SEQUENCE S1
START WITH 1
INCREMENT BY 1
MINVALUE 1
MAXVALUE 5
CYCLE;
```

---

## 🛑 NOCYCLE

`NOCYCLE` stops the Sequence after reaching its maximum value.

```text
1 → 2 → 3 → 4 → 5
                ↓
               STOP
```

### Example

```sql
CREATE SEQUENCE S1
START WITH 1
INCREMENT BY 1
MINVALUE 1
MAXVALUE 5
NOCYCLE;
```

---

## 📊 CYCLE vs NOCYCLE

| CYCLE                           | NOCYCLE                        |
| ------------------------------- | ------------------------------ |
| Restarts after reaching limit   | Stops after reaching limit     |
| Can generate values again       | Does not restart               |
| Useful when sequence can repeat | Useful when sequence must stop |
| Continues generating values     | Stops at boundary              |

# 🔄 ALTER SEQUENCE

`ALTER SEQUENCE` is used to modify an existing Sequence.

### Restart Sequence

```sql
ALTER SEQUENCE S1
RESTART WITH 1;
```

This restarts the Sequence from `1`.

### Sequence Flow

```text
CURRENT SEQUENCE

      ↓

ALTER SEQUENCE

      ↓

RESTART WITH 1

      ↓

1 → 2 → 3 → 4...
```

---

# ❌ DROP SEQUENCE

`DROP SEQUENCE` is used to permanently remove a Sequence from the database.

### Syntax

```sql
DROP SEQUENCE S1;
```

After executing this command, the Sequence object no longer exists.

* `CYCLE` allows a Sequence to restart.
* `NOCYCLE` stops the Sequence after reaching its limit.
