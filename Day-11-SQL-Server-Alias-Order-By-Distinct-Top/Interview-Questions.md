# Day 11 - SQL Server Interview Questions

## 1. What is an Alias in SQL?

Alias is another name given to a column or expression to make the output column heading more meaningful.

---

## 2. What is ORDER BY?

ORDER BY is used to sort query results in ascending or descending order.

---

## 3. What is the default sorting order of ORDER BY?

The default sorting order is ASC (ascending).

---

## 4. Can we use multiple columns with ORDER BY?

Yes.

```sql
ORDER BY DEPTNO ASC, SAL DESC;
